# Wavy Suite

Open-source (AGPL-3.0) VST3 / CLAP / AU effects inspired by well-known mixing tools, built with JUCE.
Independent project; not affiliated with or endorsed by Waves Audio. Product names of other companies are used
only to describe what a Wavy plugin is modelled on.

Status: work in progress — one plugin at a time (see RESEARCH.md). First up: **WVox**.
